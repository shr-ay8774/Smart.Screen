# Project Report Notes

## Title

Smart Resume Screening and Candidate Ranking System using RAG and Generative AI

## Main technologies

Python, Streamlit, NLP, Sentence Transformers, cosine similarity, RAG, Ollama and Llama.

## Main idea

The system first calculates a candidate score using normal NLP/ML methods. RAG then retrieves relevant resume text. Generative AI uses that retrieved text to produce explanations and interview questions.

## Why not let the LLM rank candidates?

The score is calculated separately so the result is easier to understand. GenAI is mainly used for natural-language explanation and generation.
